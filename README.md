# HDL-Design-Framework
This is contain the files needed to design a hardware. You can run compile and simulation (terminal and waveform timing diagram) by run tcl command with icarus verilog/questa.

How to do simulation :
1.  Jump to simulation folder.
2.  Run simulation tcl command "tclsh run_icarus.tcl" for icarus verilog, "tclsh run_questa.tcl" for questa.
3.  Run clean file tcl command "tclsh clean_icarus.tcl" for icarus verilog, "tclsh clean_questa.tcl" for questa.
